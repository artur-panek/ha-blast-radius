# Security

Only the latest 0.1.x alpha is supported. Reports contain entity names and structure,
even though raw source configs and template bodies are excluded.

Use GitHub private vulnerability reporting if enabled on the published repository.
If unavailable, open a minimal issue requesting a private channel; do not publish
exploit details, tokens or configuration dumps.

Include integration/HA versions, a synthetic reproduction and impact. The panel
and all data commands require administrator access. No feature is intended to
modify existing HA configuration.
